## About

A web app is created to convey a message to a musician who is a beginner. Sometimes, he may play in a wrong scale, tempo, volume, or anything. You can correct them silently.

This has 2 options: **send** and **get**.

- **Send** - a teacher or singer
- **Get** - the musician

The musician will receive the message in 3 seconds. It won't make any noise or send a notification; it will blink.

The original idea was given by [@IssacZerubbabel](https://github.com/issaczerubbabela) for church purpose.
